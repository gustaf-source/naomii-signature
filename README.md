# Naomii Email Signatures

Email signature templates and assets for Naomii Talent Solutions.

## Usage

1. Copy the relevant HTML signature file
2. Replace placeholder values (or use Gustaf's live version as reference)
3. Paste into Gmail: Settings → General → Signature → paste HTML

## Files

- `signatures/gustaf.html` — Gustaf Heydenrych's live signature
- `signatures/colleague-template.html` — Template for new team members
- `assets/` — Profile photos and images (publicly hosted via GitHub Pages)

## Adding a new team member

1. Add their profile photo to `assets/photos/`
2. Copy `signatures/colleague-template.html`
3. Replace: `FULL_NAME`, `JOB_TITLE`, `PHONE_NUMBER`, `PHONE_DISPLAY`, `EMAIL_ADDRESS`, `WHATSAPP_NUMBER`, `LINKEDIN_URL`, `PHOTO_URL`
4. The photo URL will be: `https://gustaf-source.github.io/naomii-signature/assets/photos/FILENAME`
